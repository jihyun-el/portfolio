# 검증별 비교 대상과 통과 기준

"같은 결과"라고 쓸 때 무엇을 서로 비교했고 어디까지 같았는지를 검증마다 적어 둔 기록입니다.

## 반주 엔진

| 비교 | 통과 기준 | 확인하는 것 |
|---|---|---|
| Python 제어 로직 ↔ Rust 이식 | 곡 전체 9,392프레임 비트 동일 | 이식이 참조 구현과 같은 출력을 내는지 |
| Python 전처리 ↔ Rust 전처리 | 허용오차 1e-5 | 전처리 이식의 수치 일치 |
| 입력 구간 전체 계산 ↔ 증분 계산 | 비트 동일 | 계산을 줄인 뒤에도 결과값이 같은지 |
| 변경 후 출력 ↔ 저장해 둔 기준 출력 | 동일 | 기존 동작이 그대로인지 |
| 반주가 자연스러운지 | 청취 | 수치로 정하지 않는 판단 |

## VQA 대회

| 비교 | 통과 기준 | 확인하는 것 |
|---|---|---|
| 제출한 최종 답안 두 개 ↔ 저장된 추론 결과에서 다시 계산한 답안 | SHA-256 일치 | 제출 묶음만으로 초반 다수결부터 최종 결합까지 다시 계산할 수 있는지 |

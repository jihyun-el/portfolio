# 같은 결과를 재현했다는 말의 범위

검증 결과를 쓸 때는 무엇을 입력으로 사용했고 어느 부분을 비교했는지 함께 남깁니다.

Python 참조 구현과 Rust 이식의 제어 수학을 대조한 결과는 전체 반주 파이프라인의 동등성을 의미하지 않습니다. golden 스냅샷과 같은 출력이 나오는 것도 기존 동작을 보존했다는 뜻이며 그 출력이 음악적으로 옳다는 별도 증명은 아닙니다.

VQA 대회에서는 저장된 모델 추론 결과로 최종 답안 두 개를 재계산했습니다. 저장된 CSV와 SHA-256이 일치했지만 모델 학습과 GPU 추론 전체를 다시 수행한 검증은 아닙니다.

이렇게 범위를 남겨야 다음 수정에서 어떤 확인을 반복하고 어떤 검증을 새로 해야 할지 판단할 수 있습니다.

# 같은 결과를 재현했다는 말의 범위

검증 결과를 쓸 때는 무엇을 입력으로 사용했고 어느 부분을 비교했는지 함께 남깁니다.

반주 엔진에서는 비교마다 대상과 기준을 따로 적었습니다. Python 참조 구현과 Rust 이식의 제어 수학은 9,392틱 전체에서 비트 단위로 같았습니다. 앞단은 허용오차 1e-5로, 창 전체 계산과 증분 계산은 비트 단위로 대조했습니다. golden 스냅샷 비교로는 기존 동작이 그대로인지 확인했고, 반주가 음악적으로 자연스러운지는 청취로 판단했습니다.

VQA 대회에서는 저장된 모델 추론 결과로 최종 답안 두 개를 다시 계산했고, 저장된 CSV와 SHA-256이 일치했습니다. 제출 묶음 안에서 초반 다수결부터 최종 결합까지 모든 단계를 다시 계산할 수 있습니다.

이렇게 범위를 남겨야 다음 수정에서 어떤 확인을 반복하고 어떤 검증을 새로 해야 할지 판단할 수 있습니다.

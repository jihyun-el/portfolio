사진 속 글자를 읽고 답하는 VQA 대회. 5인 팀 A011의 팀장으로 가설 설계, 실험 배분, 공통 실행 환경을 맡음

## 실험 설계
<!-- anchor: experiments -->

출발점 모델과 데이터 분할(같은 사진은 한쪽에만)을 고정하고 가설을 팀원 4명에게 OCR·모델 크기·해상도·앙상블 축으로 배분. 모델 크기 × 해상도 **2×2 교차**로 두 효과를 분리

SSAFY 16기 교육생 대상 사진 속 글자 VQA 대회에서 5인 팀 A011의 팀장을 맡았습니다. 가설을 설계하고 팀원에게 실험 축을 배분했으며, 공통 실행 환경과 발표를 담당했습니다.

모델 크기 4B/8B와 이미지 해상도 512²/768²를 조합한 2×2 실험으로 효과를 구분했습니다. 같은 이미지가 학습과 검증에 나뉘어 들어가지 않도록 이미지 단위로 분할했습니다.

공통 출발점은 Qwen3-VL 4B를 4비트로 올리고 LoRA를 한 에폭 학습한 조건이었습니다. 학습 4,297문항, 자체 검증 1,074문항, 최종 확인 1,343문항을 이미지 해시로 묶어 고정했습니다. 팀원 4명에게 모델 크기·해상도·OCR·앙상블 등의 축을 나누고 같은 분할과 실행 패키지를 사용했습니다.

<!-- figure:vqa-matrix -->

해상도를 512²에서 768²로 바꾼 효과는 +3.99%p, 모델을 4B에서 8B로 바꾼 효과는 +2.23%p였습니다. 네 조건을 교차 비교하니 두 효과의 겹침이 약 −0.03%p였습니다. 두 방향을 함께 적용할 판단 근거가 생겼습니다.

## 모델 학습

4비트 QLoRA에서 대형 VLM의 BF16 LoRA로 진행. 보기 순서 섞기와 보기 확률 채점을 적용

4비트 QLoRA에서 대형 VLM의 BF16 LoRA로 진행하며 보기 순서 섞기와 보기 확률 채점을 사용했습니다. 후반 학습 레시피는 상위 팀이 공개한 자료를 참고했습니다.

## 실행 검수

설정에서 해상도를 바꿨는데 학습 코드가 고정 해상도를 쓰던 문제를 발견. 실제 입력 해상도 출력과 모델 해시 대조를 추가

설정 파일에는 해상도를 바꿨지만 실제 학습 코드가 고정 해상도를 사용하는 문제가 있었습니다. 팀원의 실행이 같은 결과를 만드는 일을 겪고, 실행 전에 실제 입력과 설정을 확인하는 검수를 보강했습니다.

팀원이 1시간 동안 다른 조건을 학습했는데 adapter 해시까지 같은 복제본이 된 사례였습니다. 설정 파일만 보는 대신 실행 시 실제 입력 해상도를 출력하고, 모델 파일 해시와 저장된 확률을 비교하도록 바꿨습니다. 큰 GPU 실행 전에는 실행할 ZIP·노트북 경로를 CPU에서 감사했습니다.

## 평가 규칙

앙상블 규칙과 채택 기준을 점수를 보기 전에 코드로 고정. 자체 검증 세트를 반으로 나눠 양쪽 모두 손해가 없을 때만 채택

추론 방식을 추가할 때는 자체 검증 세트를 앞·뒤 절반으로 나눠, 양쪽 모두 손해가 없고 전체 정답이 1문항 이상 늘 때만 채택했습니다. 불확실한 문항 목록과 결합 규칙도 결과 전에 남겼습니다. 효과가 없던 학습 해상도 변경·타일링·추가 에폭은 결과와 함께 기록했습니다.

후반의 BF16 학습과 보기 순서 섞기는 함께 바꾼 조건이라 하나의 변경으로 기록했습니다. 최종 두 답안 중 하나에는 Public 점수를 본 뒤 선택한 결합이 포함됐고, 다른 하나는 미리 정한 로그 평균 규칙으로 만들었습니다. Private에서 0.97855를 낸 쪽은 앞의 답안이었고, 규칙 답안과의 차이는 2~4문항이었습니다.

## 재현

검증에 사용한 입력은 저장된 예측 CSV 54개였습니다. 초기 다수결, 모델끼리 답이 갈린 434문항, 불확실한 298문항, 최종 결합을 다시 계산했습니다. [실험 결과와 채택 기준에 관한 트러블슈팅 글](/writing/experiment-gates/)에는 팀 운영에서 무엇을 미리 정했고 무엇이 사후 선택이었는지 정리했습니다.
